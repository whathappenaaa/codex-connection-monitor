# Codex 连接灯

此插件包含一个独立运行的 Windows 桌面伴随工具。根据本技能文件位置向上两级找到插件根目录。

用户要求打开连接灯时，用 `Start-Process -FilePath '<插件根目录>\CodexConnectionMonitor.exe'` 启动可视窗口。若二进制不存在，先运行插件内的 `scripts/build.ps1`。窗口重复启动有单实例保护。

用户要求诊断时，执行 EXE 的 `--diagnose <临时 JSON 文件绝对路径>`，等待进程结束再读取输出。结果可能含任务名称、标识、时间和不带凭据的探测结果，不含令牌或 Cookie；不可不经删改就公开上传。用户要求核对额度时，`--usage-check <临时 JSON 文件绝对路径>` 只输出额度周期、剩余比例、重置时间和状态。

解释状态时以当前任务的日志证据为准。普通 HTTP 探测成功、401 或 403 只能说明入口响应，不能推断对话畅通。模型长时间没有输出也可能是思考或工具运行，不要直接说断网。日志不可读或证据过期应报告未知。

关闭窗口会收起至托盘，连接与额度监测继续。托盘汇总系统网络、任务和探测状态：红、黄、绿、蓝、灰依次优先；额度状态不会改变托盘颜色。退出使用托盘右键菜单。程序不添加开机启动、不修改系统代理、不调用模型 API；额度由本机官方 App Server 读取，系统代理仅转交给其子进程。
