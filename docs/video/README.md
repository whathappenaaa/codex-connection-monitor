# B站视频素材包

项目：Codex 连接灯 1.4 · 作者：B站那年松江

建议先读 [项目策划](策划.md)，再按 [逐字稿](逐字稿.md) 和 [分镜表](分镜表.md) 录制。

- [完整逐字稿](逐字稿.md)：约 7 分钟，包含现场结果分支。
- [逐镜操作与字幕重点](分镜表.md)：录屏操作、停顿、剪辑和字幕提示。
- [录制检查表](录制检查表.md)：开录前与投稿前检查。
- [标题、简介、标签及置顶评论](发布文案.md)：发布确认后可直接使用。
- [封面可编辑 SVG](cover.svg) / [封面 PNG](cover.png)：1920×1080 自制素材，上传时检查裁切预览。
- [分句字幕文稿](字幕文稿.txt)：无虚构时间轴，按实际配音在剪辑软件内对齐。

状态示意图和仓库截图使用测试数据，已明确标注。真实录屏中的任务名称、账号信息和聊天内容由录制者检查后决定是否公开。本包不含录制完成的视频或配音，也不会自动投稿。
