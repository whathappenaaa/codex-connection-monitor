## 00:00–00:35 问题开场

[展示已裁切的真实重连提示，再切到连接灯。]

你有没有遇到过这种情况：网页能打开，视频也能看，但是 Codex 一直显示正在重连。或者它突然没动静了，你不知道应该继续等，还是重新发送。

还有一个小麻烦，就是用着用着，想看一下账号还剩多少额度，又要切过去找。

所以我做了一个 Windows 桌面小工具，叫 Codex 连接灯。今天给大家实际演示一下，也把完整源码免费开源出来。

## 00:35–01:00 起因与开发方式

[展示小号窗口与作者署名。]

大家好，我是那年松江。这个工具的起点，就是我自己使用 Codex 时遇到的一次连接中断。

我提出需求，使用 Codex 辅助开发，再根据实际使用情况调整任务名称、窗口大小和中英文切换。现在又加上了剩余额度和更明显的托盘颜色。

## 01:00–02:00 看懂连接状态

[展开中号窗口，鼠标指向任务名、最后回应和记录。]

先看上面这一块，它对应的是正在监测的任务。可以自动跟随，也可以手动选定一个任务。

现在主状态只看有没有检测到断开。绿色表示暂时没有检测到中断，有最近的成功记录或者入口响应，不保证接下来一直在线。

红色表示系统没有网络、这个任务中断了，或者 ChatGPT 入口探测失败。鼠标放上去可以看具体原因。任务出现过中断后，要等这个任务产生恢复记录才会消除提示。

灰色表示无法确认，比如还没有识别任务，或者日志暂时读不到。思考、执行工具、空闲和本轮结束，不再分别显示不同的颜色。窗口和托盘用的是同一个判断。

下面的网络探测是另外一组信息。公共入口能访问，不等于 Codex 对话一定正常。HTTP 403 也只说明入口返回了拒绝访问的响应，不是电脑断网。

## 02:00–03:30 托盘与拔网线实验

[点击收起，放大托盘图标。]

平时不想一直摆着这个窗口，可以把它收进托盘。窗口隐藏以后，监测还会继续。

我把整枚图标做成了状态颜色，并加了符号。鼠标放上去，可以查看异常原因和额度摘要。这里汇总了电脑网络、任务连接和入口探测，窗口和托盘会同步变色。

[先发出一个公开的演示请求，确认 Codex 已经开始输出。]

接下来做一个真实测试。我先确认 Codex 正在输出，然后手动把网线拔掉。

[手动拔线，完整录下变化。等待可加速，标注“等待过程已加速”。]

现在日志每半秒检查，网络每三秒探测，单次限时两秒。但这仍不保证拔线的一瞬间就变色。Codex 尚未写出错误时，工具也无法提前知道，我们看实际结果。

[根据画面选择下面一句；不成立的句子删除。]

**出现红色：**现在已经显示红色了。鼠标放上去，能看到这次是本机网络不可用、任务重试，还是入口探测失败，按实际显示的原因判断。

**仅入口探测失败：**这次先发现的是入口探测失败，所以变红。它还不是模型流已断开的直接证据，需要结合 Codex 的实际表现判断。

**没有发生中断：**这台电脑可能还有其他可用网络，或者这次没有捕捉到明确的异常，因此这段不能当作成功复现的断网结果。

[接回网线。]

现在接回网线。入口恢复，并不表示刚才的对话已经继续。我们还要看 Codex 有没有新的输出。如果那次请求已经结束，就重新发一个简单请求，再观察状态。

## 03:30–04:15 剩余额度

[恢复窗口，指向账号额度；不要把台词里的示例数字当成实际值。]

这里是账号共享的剩余额度，不是当前这一个任务单独的额度。接口返回几个周期，软件就显示几个，不会所有人都固定显示五小时和每周两条。

百分比来自官方账号接口，旁边是按电脑本地时间显示的重置时间。它会定期刷新，也可以手动检测。

断网时如果更新失败，会保留上次结果并标记旧数据，不能把旧数字当成实时余额。到了重置时间，也要重新查询确认，不会自己假定恢复满额。

额度用尽或者查询失败，不会让连接灯变红，因为这和网络断线是不同的问题。

## 04:15–05:00 日常操作

[依次切换小、中、大；自适应；中英文；选择任务；收起与恢复。]

平时我更喜欢用小号。顶部的小、中、大可以直接切换，想看详细说明就用中号或者大号。

自适应会根据内容调整高度。如果你自己拖动边框，就会停止自动调整，避免程序覆盖你的操作。再次点击尺寸按钮，就能恢复。

右上角可以切换中英文。自动跟随不是想看的任务时，也可以手动选择。

关闭窗口会继续留在托盘。彻底退出，要从托盘的右键菜单退出。

## 05:00–06:00 下载、启动与额度条件

[仓库 → Releases → portable ZIP → 完整解压 → 启动；只在仓库和附件实际发布后录制。]

下载链接我会放在视频简介和置顶评论。打开项目页面，进入 Releases，下载名字里带 portable 的 Windows 压缩包。只想使用软件，不需要下载源码。

下载以后先完整解压，再双击里面的程序。这个版本不需要安装 Python 或 Node，也不用输入 API Key。

额度功能需要你在本机官方 Codex 里登录。如果没有找到 Codex 程序，可以从托盘菜单手动指定 codex.exe。没有返回额度数据时，会说明原因，不会显示一个假的零。

这是免安装版。更新时先退出旧程序，再解压新版。以后不想用了，从托盘彻底退出，再删除解压目录即可。

## 06:00–06:45 数据来源与边界

[指向 README 的数据来源与限制。]

它会只读分析本机的 Codex 日志和任务名称，并通过官方 Codex 查询账号额度。连接灯不保存账号令牌，不发起模型任务，也没有上传聊天内容的功能。

另外，它会定期探测微软和 ChatGPT 的公共入口，所以不是完全离线的软件。

它不能修复代理、服务器或者 TLS 错误。连接判断依赖本地日志，Codex 更新后可能需要适配。遇到证据不足的时候，正确的表现就是显示未知。
