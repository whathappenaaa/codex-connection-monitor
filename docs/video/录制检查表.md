# 录制与投稿检查表

## 开录前

- [ ] GitHub 仓库和 Release 已公开，免安装附件下载链接可用。
- [ ] 运行的是 1.3.0，关闭重复实例；将托盘图标放在可见区域。
- [ ] 使用可以公开的演示任务，清理画面中的其他任务名、聊天、通知和个人文件路径。
- [ ] 检查录屏确实包含悬浮窗、托盘及鼠标悬停提示。
- [ ] 试录 20 秒，回听麦克风，不爆音、不被系统输出覆盖。
- [ ] 本地保存录屏；拔线不会中断录制或损坏正在上传的文件。
- [ ] 确认当前网络路径。若另有 Wi-Fi 或其他网络，拔掉一根网线可能不会中断连接。
- [ ] 本人操作网线、账号登录和系统设置；不通过自动化强制断网。

## 实验时

- [ ] 先看到 Codex 正在输出，再手动拔线。
- [ ] 保留完整原始录像，记录状态变化和等待时长。
- [ ] 按实际结果解释红色、黄色或未复现，不预先断言某个结果。
- [ ] 恢复网络后观察新回应；必要时重新发送公开的简单请求。
- [ ] 结束后确认网络恢复、软件与任务仍正常。

## 剪辑与投稿前

- [ ] 等待片段加速有字幕；状态示意图与测试数据有标识。
- [ ] 没有将不同实验的画面剪接成同一次实时结果。
- [ ] 没有把灰色说成断网，把绿色说成持续在线保证。
- [ ] 没有把额度低／刷新失败说成网络中断。
- [ ] 确认账号、任务名、聊天、诊断文件和二维码均可公开。
- [ ] 根据实际成片调整章节时间与字幕时间轴。
- [ ] 简介和置顶评论中的 GitHub、Release 链接均可打开。
- [ ] 封面裁切正常，未宣称 OpenAI 官方产品、全平台支持或万能修复。
- [ ] 保留原始录像与配音工程，便于日后修改。
