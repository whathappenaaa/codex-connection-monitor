## 简介（可复制）

Codex 一直重连，或者长时间没有回应时，我想更方便地查看最近的连接记录，于是提出需求，用 Codex 辅助做了这个 Windows 桌面小工具。

Codex 连接灯 1.4 支持：

- 任务连接证据与独立网络探测
- 收起后继续监测，整枚托盘图标按综合状态变色
- 账号剩余额度、实际周期及重置时间
- 小中大三档、自适应、置顶、中英切换

免费开源，MIT 许可证。

源码：https://github.com/whathappenaaa/codex-connection-monitor

免安装下载：https://github.com/whathappenaaa/codex-connection-monitor/releases/latest

这是独立开发的非官方工具，不负责修复网络；连接判断来自本地日志，证据不足时显示未知。额度通过本机已登录的官方 Codex 查询。目标平台是 Windows 10/11 x64，目前实测 Windows 11。

## 置顶评论（可复制）

下载：https://github.com/whathappenaaa/codex-connection-monitor/releases/latest

请选择名字带 portable 的 Windows 免安装包，完整解压后运行。关闭窗口会留在托盘，右键菜单才能彻底退出；托盘图标被折叠时可手动拖到任务栏常显区。

绿色表示未检测到断开，有近期成功记录或入口响应，不保证持续在线；灰色也不等于断网。额度是账号共享的定期快照，刷新失败时会标记旧数据。

问题反馈请到仓库 Issues，提供软件、系统和 Codex 版本以及复现步骤。截图先遮挡私人内容，不要上传登录文件、完整聊天或原始日志。

## 常见评论回复

**为什么还是灰色？** 灰色表示证据不足。先确认 Codex 正在产生新的活动、任务选择正确，或在记录中查看日志是否可读。没有输出不一定断网。

**403 是断网吗？** 不是。它说明该入口已经返回 HTTP 响应，不能证明模型对话可用，也不属于传输断线。

**为什么额度读不到？** 需要已登录的官方 Codex 和支持额度接口的版本。查看具体提示；找不到程序时可从托盘菜单指定 codex.exe。

**会读取聊天内容吗？** 本机连接日志按固定规则分类，任务名在本机显示；软件没有聊天上传功能。完整数据说明请看 README。

**有 Mac 版吗？** 当前发行包仅面向 Windows x64，没有承诺其他平台版本。
