# 项目与视频策划

## 定位

为 Windows 版 Codex 用户提供一个方便查看的桌面窗口：连接最近是否有成功或失败的证据、公共入口是否响应、账号还剩多少额度。收起窗口后，托盘仍提供综合状态。

软件不修复网络，不承诺实时在线判断，不提供剩余提问次数估算。免费、MIT 开源，作者为 B站那年松江。介绍时说“我提出需求，用 Codex 辅助开发并实际测试”，不把未经验证的兼容性描述成全部支持。

## 受众与目标

主要受众：使用 Windows 版 Codex，遇到重连、无回应、反复切换查看额度的用户。

观众看完能完成三件事：理解颜色含义、下载并启动软件、知道遇到问题如何反馈。项目传播以真实演示和清晰说明为主，不承诺播放量、收益或软件万能效果。

## 视频结构

主标题：Codex 掉线了吗？额度还剩多少？我做了个免费开源连接灯

形式：纯录屏＋本人配音；1920×1080 横屏；目标 6–8 分钟。正常操作保持实时，等待重连的片段可以加速，但需标注。

开场展示真实重连报错；接着讲工具和颜色。核心演示是收起窗口后手动拔网线、观察托盘，再接回网络。接着展示剩余额度及其更新时间，最后完成下载运行流程、能力边界和开源介绍。

语言：自然口语，先演示再解释；不要朗读过多协议名或代码。关键数字只读录制时的实际值，不提前写死。

## 制作步骤

1. 发布工程：完成代码与测试、公开仓库、Release 和可下载免安装包。
2. 素材准备：使用可公开的演示任务、检查托盘常显、准备干净的下载与解压目录。
3. 实机试录：确认录屏能录到悬浮窗和托盘，麦克风音量合适，断网后录制文件仍在本地保存。
4. 正式录制：按分镜分别录短段；真实实验可先完整录，再配旁白说明实际结果。
5. 剪辑：删去无意义停顿，等待片段标注加速，必要处放大托盘和额度区域。
6. 投稿：校对下载链接、章节时间、字幕和截图中的私人信息。

## 开源运营

首版采用 MIT，全部已有功能开放。仓库提供构建步骤、使用说明和 Issues 模板。优先处理日志兼容、额度接口兼容、不同 DPI 下的界面问题。

视频评论里的可复现问题整理为 Issues；不要求观众上传私人日志。后续功能先以实际反馈决定，不在视频承诺尚未实现的安装器、自动更新或全平台支持。

## 素材与署名

封面由项目自制矢量图形、文字和图标组成，不使用第三方音乐或图片。若剪辑时另加音乐，由录制者选择有权使用的音源。封面和脚本随项目 MIT 开源；Codex 名称用于说明兼容对象，不暗示官方合作。
