# Codex 连接灯 v1.3.0

作者：B站那年松江 · MIT 开源 · Windows x64 免安装

## 本版变化

- 新增账号共享剩余额度、实际周期和本地重置时间；更新失败保留并标记旧数据。
- 托盘整枚图标按综合连接状态变色，收起窗口后继续监测；异常原因与额度摘要可悬停查看。
- 红／黄／绿／蓝／灰分别表示明确中断、异常待确认、近期成功证据、本轮结束和未知。
- 修复退出时托盘仍引用已释放 Icon 导致的 .NET 异常；测试覆盖退出、隐藏与切换颜色。
- 保留三档尺寸、自适应、中英切换、真实任务名称、作者署名和置顶。
- 提供完整源码、构建与测试脚本，以及 B站视频逐字稿、分镜、字幕文稿、封面与发布文案。

## 下载与运行

下载附件中名字含 `win-x64-portable.zip` 的文件，完整解压后双击 `CodexConnectionMonitor.exe`。自动生成的 Source code ZIP 面向开发者。

不需要 Python、Node.js 或 API Key。额度功能需要已登录的官方 Codex，找不到程序时可在托盘菜单指定 `codex.exe`。关闭窗口会收起到托盘，右键菜单可彻底退出。

`SHA256SUMS.txt` 可用于核对附件完整性。当前程序未商业签名，也没有安装器或自动更新。

## 验证

本地通过 87 项规则与解析测试、18 种三档双语缩放布局、界面与隐藏托盘交互，以及成功／未登录／不支持／10 秒超时四种独立额度协议测试。独立查询结果已与 Codex 当前账号额度核对。

验证环境为 Windows 11 x64（10.0.26200）及 Codex CLI 0.158.0-alpha.2.1。目标平台含 Windows 10/11 x64，但尚未完成 Windows 10 实机验收。

## 使用边界

本项目非 OpenAI 官方产品。绿色是近期连接证据，不保证持续在线；灰色不等于断网。HTTP 401/403 和额度更新失败不会被判为断网。网络异常不由本软件修复，日志格式与额度接口可能随 Codex 更新变化。

额度是账号共享的定期快照；到重置时间后重新查询确认。程序不复制或保存令牌，不创建模型任务。反馈问题时请先遮挡任务名称等私人信息，不上传原始日志或登录文件。
