# Codex 连接灯 v1.3.1

作者：B站那年松江 · MIT 开源 · Windows x64 免安装

修复 Codex 正在运行，但连接灯显示“尚未识别当前任务”、托盘灰色的问题。

商店版 Codex 会将桌面日志写入 Windows 应用包缓存。1.3.0 仅按普通目录寻找日志，从 Codex 内启动时可能受 Windows 路径重定向影响而正常，从资源管理器独立启动却会读到空占位文件。1.3.1 直接发现两种目录，优先读取同名日志中有内容的应用包副本。

没有当前任务证据时仍显示未知，不使用其他旧任务冒充在线；额度、网络探测与托盘颜色规则保持兼容。

## 下载与更新

下载 `codex-connection-monitor-v1.3.1-win-x64-portable.zip`。先从托盘退出旧版，再完整解压新版并运行 `CodexConnectionMonitor.exe`。如需保留显示偏好，可将自己的 `settings.json` 复制到新版目录。

无需 Python、Node.js 或 API Key。额度需要已登录的官方 Codex。当前程序未商业签名，没有安装器或自动更新。`SHA256SUMS.txt` 用于核对附件完整性。

## 验证

- 96 项状态、额度及日志发现测试，包含普通目录、应用包目录、同名空占位文件，以及不借用旧任务等回归场景。
- 18 种尺寸、双语与缩放布局；隐藏托盘及退出交互。
- 额度成功、未登录、接口不支持和 10 秒超时四种协议测试。

连接判断仍依赖 Codex 本地日志，绿色表示近期连接证据，灰色表示证据不足。完整说明见仓库 README。
