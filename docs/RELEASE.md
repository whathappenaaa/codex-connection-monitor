# Codex 连接灯 v1.4.0

作者：B站那年松江 · Windows x64 · MIT

本版针对“断开提示滞后”和状态过多的问题：窗口与托盘同步显示，主要只看是否检测到断开。

- **红色：连接中断。** Windows 无可用网络、当前任务中断未恢复，或 ChatGPT 入口探测失败；鼠标悬停查看具体原因。
- **绿色：未检测到断开。** 有近期成功记录或入口响应，没有未恢复的任务错误。
- **灰色：无法确认。** 日志不可读、任务未识别、数据过期或网络切换后正在重新确认。

空闲、思考、工具运行和本轮结束不再单独变色。额度不影响连接颜色。

## 响应速度

日志每 0.5 秒检查，网络每 3 秒探测，单项限时 2 秒。Windows 网络变化立即触发更新。各入口独立发布结果，慢日志、额度、DNS 和代理等待不会阻塞界面上的网络提示。网络切换前的迟到结果会被丢弃。

修复 Codex 日志达到大小上限、换文件后丢失当前任务的问题；同一次桌面运行的日志分段会接续读取。

入口异常的调度预算约为 0–5.5 秒，实际时间受系统与网络影响。Codex 断线仍须等它把错误写进日志；不能保证瞬时检测。探测失败不是模型流断开的直接证据，绿色也不是持续在线保证。

## 下载与更新

下载附件 `codex-connection-monitor-v1.4.0-win-x64-portable.zip`，先从托盘退出旧版，再解压运行。可复制自己的 `settings.json` 保留显示偏好。无需 Python、Node.js 或 API Key。

`SHA256SUMS.txt` 用于核对下载完整性。本项目没有自动更新或安装器，程序尚未进行商业代码签名。

## 验证

114 项状态、额度、日志与传输时限测试；18 种双语、尺寸、缩放布局；界面与托盘一致性、慢日志不阻塞提示、快速失败不等待另一入口、额度协议成功／未登录／不支持／超时测试。

超时与取消使用本机 TCP/HTTP 测试服务验证，没有操作用户的实际网络连接。真实拔线后的端到端时延仍需按当时环境测量。
